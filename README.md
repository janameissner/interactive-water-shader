# Interactive Real-Time Water Shader in Unity

Development of a modular water shader in URP featuring depth-dependent coloring, animated surface details, vertex-based waves, refraction, shoreline foam, and local object interaction.

## Mandatory Objectives
- Depth-dependent water color
- Animated normal maps / noise
- Vertex displacement (Gerstner waves)
- Adjustable shader parameters
- Small demo scene

## Target Objectives (Core Scope)
- Depth-based shoreline foam
- Screen-space refraction
- Local object interaction (ripples or waves)
- Performance comparison of various feature combinations

## Optional Objectives
- Caustics, underwater view / fog, reflection variants, multiple interaction sources, quality levels / LOD
